# kasa

A core banking backend in Go — a real double-entry ledger (integer money, never floats), built as a modular monolith, with a thin web app that visualizes the accounting behind every action.

Status: early build. See `plan/` (not tracked in git) for the full design and roadmap.

## Quickstart

```
make setup   # install tool dependencies
make run     # start the API
make test    # run tests
```
